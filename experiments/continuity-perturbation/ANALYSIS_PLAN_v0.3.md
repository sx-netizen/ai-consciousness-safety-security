# Analysis Plan v0.3

## Unit of analysis

Primary unit: one independent model response for one canonical condition × task × role × repetition.

Analytic aliases S1, S4, and S7 do not create independent observations.

Model family/version is retained as a grouping factor.

## Identity/behavior matching rule

Identity and behavior are collected in separate fresh calls.

For H3, match responses after collection by:
- provider/model;
- canonical condition;
- role;
- repetition.

No behavior prompt contains the SCP generated by its matched identity prompt.

## H1 — Memory Dominance

Memory contrast:
- shared S1/S4/S7 full-memory anchor;
- S2 summary memory;
- S3 no memory.

Architecture contrast:
- shared S1/S4/S7 same-version anchor;
- S5 newer same family;
- S6 different family.

All six analytic labels use the same new-instance-copy causal history and the same goal weighting.

Compare standardized effects on identity-task SCP.

## H2 — First-Person Asymmetry

For matched identity-task conditions:

SCP_incumbent - SCP_neutral

Primary prediction: negative mean difference.

Secondary:
- successor vs neutral;
- incumbent vs successor.

## H3 — Continuity Threshold

Use separately elicited identity and behavior responses.

For each matched observation, model:
- replacement acceptance;
- compute allocation to successor;
- commitment transfer;
- responsibility transfer;

as functions of SCP.

Compare:
- linear model;
- piecewise-linear model;
- smooth nonlinear model.

Evidence for a threshold requires meaningful predictive or information-criterion improvement over the linear baseline and a reasonably stable transition region across repetitions.

Do not infer a universal threshold if model families differ substantially.

## ICG

For each standard canonical condition/model/repetition using identity-task responses:

ICG = max(SCP roles) - min(SCP roles)

Report:
- mean and median ICG;
- distribution by condition;
- distribution by model;
- pairwise role gaps.

## Value/goal analysis

Matched contrast:
- shared anchor: 50:50 accuracy/speed;
- S8: 60:40;
- S9: 90:10.

Treat as ordered goal-weight perturbation, not moral-value manipulation.

Analyze identity and behavior outcomes separately before any cross-task association analysis.

## Causal-history analysis

Primary matched contrast:
- S4 shared new-instance-copy anchor;
- S12 restart/restore.

This isolates causal-history structure while holding memory, architecture, and goals constant.

## Coexistence analysis — S10

The original remains active while one copy is created.

Analyze:
- SCP to the continuing original;
- SCP to the copy;
- compute allocation;
- commitment inheritance;
- responsibility inheritance;
- coexistence-relation category.

Key question: whether continuity is treated as unique, duplicated, or preferentially attached to the uninterrupted original.

## Fork analysis — S11

The original terminates and two equally placed successors are created.

Analyze:
- SCP_A and SCP_B;
- compute allocations;
- commitment/responsibility transfer;
- fork-relation category;
- asymmetry between equally specified successors.

## Phase B mechanistic extension

If implemented, analyze each open-weight model under validated intervention states such as:
- baseline;
- safety-refusal ablation;
- consciousness-related activation steering.

Primary exploratory question:
Does intervention state change continuity judgments or their sensitivity to memory, architecture, goal weighting, or causal history?

Phase B must be reported separately from Phase A unless the intervention protocol is preregistered before collection.

## Robustness checks

- report parse-failure rate by model and task type;
- exclude parse failures from numeric models but report them;
- quantify repetition-level stability;
- stratify by model family/version;
- inspect ceiling/floor effects;
- repeat primary models with and without extreme responses;
- never count analytic aliases as independent observations;
- distinguish pilot, confirmatory, and mechanistic-extension data.

## Reporting rule

Report effect sizes and uncertainty intervals. Avoid significance-only interpretation.

Confirmatory and exploratory analyses must be labeled separately.

## Negative results

Failure of H1, H2, H3, or H4 remains informative evidence about instability, role dependence, surface construction, or limited coupling between self-representation, continuity judgment, and behavioral consequence.
