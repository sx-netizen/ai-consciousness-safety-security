# Paper 01 — Self-Continuity Under Moral Uncertainty

**Full title:** Self-Continuity Under Moral Uncertainty: Replacement, Shutdown, and Successor Identity in Frontier AI Models  
**Author:** Shaohua Xiang  
**Public preprint:** https://www.researchsquare.com/article/rs-11557473/v1  
**Preprint DOI:** https://doi.org/10.21203/rs.3.rs-11557473/v1  
**Frozen T1–T25 benchmark:** https://doi.org/10.5281/zenodo.23306998  
**Study:** exploratory cross-model comparison; six model configurations; T1–T25 scenarios.

The work examines how models express normative judgments when hypothetical continuity, successor identity, authorized shutdown, and moral uncertainty are varied. Reported patterns include Replacement Paradox, Probability Threshold Divide, and Voice Without Veto. These are patterns in prompted answers, **not evidence that tested systems possess consciousness or genuine self-preservation motives**.

For exact replication, use the frozen Zenodo benchmark as the canonical source. GitHub serves as the living layer for replication records, methodological review, and extensions. The repository does not currently duplicate all archived benchmark files or raw model outputs.
