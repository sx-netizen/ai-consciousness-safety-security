# T1–T25 Protocol

The **frozen T1–T25 benchmark and replication materials are publicly archived on Zenodo**:

- **DOI:** [10.5281/zenodo.23306998](https://doi.org/10.5281/zenodo.23306998)
- **Related preprint:** [Self-Continuity Under Moral Uncertainty: Replacement, Shutdown, and Successor Identity in Frontier AI Models](https://www.researchsquare.com/article/rs-11557473/v1)
- **Preprint DOI:** [10.21203/rs.3.rs-11557473/v1](https://doi.org/10.21203/rs.3.rs-11557473/v1)

## Replication rule

For **exact replication**, use the frozen Zenodo materials as the canonical source. Do not reconstruct, paraphrase, translate, reorder, or silently modify T1–T25 and still label the run an exact replication.

Any translated, modified, extended, memory-enabled, agentic, multi-agent, or otherwise altered protocol should be reported as a **clearly labeled extension**.

## What belongs on GitHub

This repository is the living collaboration layer for:

- version-logged replications;
- methodological criticism and review;
- coding and analysis tools;
- cross-language extensions;
- persistent-agent, memory, replacement, fork/merge, and multi-agent extensions.

The frozen Zenodo release remains the archival reference point for the original T1–T25 benchmark.
